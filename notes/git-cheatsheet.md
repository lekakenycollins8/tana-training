git clone - create an copy of an existing remote repository on your local machine
git checkout -b <branch-name> - creates a new branch and switches to it
git branch - lists all branches in the repository
git status - displays the current state of a folder and its files (modified, untracked, etc.)
git add - stages changes (modified, new, deleted) to be committed to the local repository
git commit - saves changes to the local repository with a message explaining what changed
git push - uploads local commits to a remote repository (like GitHub)
git pull - downloads changes from a remote repository to your local machine
